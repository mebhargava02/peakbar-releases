What's new in PeakBar 1.0.3

🌐 Internet card — see your real speed

A new card on the dashboard shows live latency to the internet every few seconds, with a colored dot so you can spot trouble at a glance. Tap Test Speed to run an on-demand download/upload test against Cloudflare and see your actual Mbps — no need to leave PeakBar for fast.com or speedtest.net.

⚡ Latency at a glance

Green under 60 ms, yellow up to 150 ms, red above. If you're offline, you'll know immediately.

Everything else stays 100% on-device. The speed test is the one exception — it contacts speed.cloudflare.com only when you tap the button.
